# 🛒 E-commerce Website

##  Description
This is a responsive E-commerce web application that allows users to browse products, view details, and add items to a shopping cart. The project focuses on building a dynamic and user-friendly shopping interface using frontend technologies.

---

##  Features
-  Product listing with images, price, and details
-  Search and filter functionality
-  Add to cart and remove from cart
-  Cart data stored using localStorage
-  Responsive design for mobile and desktop
 
---

##  Tech Stack
- HTML  
- CSS  
- JavaScript
